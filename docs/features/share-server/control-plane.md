# 实例管控面第一版

本版面向实例管理员，提供持久化业务资料、审核、人工任务、资源文件和目录管理。
组织成员登录、组织隔离和运行时策略执行仍是独立后续能力。

## 管理对象与操作

| 模块 | 可用操作 |
| --- | --- |
| 配置 | 版本、客户端 Base URL、模型别名与目标范围；审核后下载无密钥配置 JSON |
| 成员 | 联系邮箱、用户组、组织职务、关联设备 ID；共享目录按已审核成员关联分组 |
| 策略 | 主体、资源、动作和允许／拒绝；已审核策略匹配模拟 |
| 审批 | 申请人、关联记录 ID、申请理由；沿用审核、驳回、归档和恢复 |
| 资源 | 版本、通道、平台、下载地址和摘要；实际文件上传与管理员下载 |
| 合作网关 | 地址、组织标识、指纹、联系邮箱和协商范围；人工评审资料 |
| 任务 | 负责人、截止日期、关联资源与验收标准；审核后跟踪人工进度 |
| 设置 | 显示名称、联系邮箱和公告；最近更新的已审核资料显示在概览 |
| 设备 | 设备详情、注册审批、停用／恢复、接入事件和撤销记录 |
| 共享目录 | 能力、知识、设备与成员视图；保留搜索、筛选、撤销和重试 |

所有新界面支持中文／英文。草稿允许暂缺字段；提交审核时检查结构化必填项。
名称与说明继续保留。旧文字记录可以直接读取；首次编辑保存后使用结构化字段规则。
关联设备是管理声明，不能据此认定设备所有权或授予运行时权限。

## 技术契约与状态

- `ConsoleRecord.fields` 是按模块白名单验证的字符串映射；每字段最多 4000 字符。
  URL 只允许无用户名／密码的 HTTP(S) 地址；日期、邮箱、摘要与枚举分别校验。
  非草稿内容冻结；更新继续使用 revision 防止覆盖并发修改。
- `GET /api/v1/console/distribution/:id/config` 仅导出已审核且字段完整的配置，包含
  `schemaVersion/version/protocol/baseURL/models/authentication`，不含 API Key。
  该文件用于人工客户端配置，不宣称现有 Desktop 支持自动导入或推送。
- `POST /api/v1/console/policies/evaluate` 接收 `subject/resource/action`，只匹配已审核
  策略。主体／资源支持全值 `*`；动作使用逗号分隔，支持全值 `*`。拒绝优先、默认拒绝。
  返回 decision、matchedIds 和 `mode: simulation`，不修改运行时授权。
- `POST /api/v1/console/tasks/:id/progress` 接收 `revision/progress/result`。
  审核后任务为 queued；允许 queued → in_progress/cancelled，
  in_progress → completed/cancelled。终态必须有结果／原因，最多 12000 字符。
  进行中不可归档；恢复草稿重置进度，原变更历史保留。结果不复制到审计正文。
- `POST /api/v1/console-assets` 接收唯一 multipart `file` 字段，文件最多 20 MiB；
  返回 `{url, sha256, name, size}`。`GET /api/v1/console-assets/:sha256` 下载附件。
  两者均由实例管理员访问控制保护。摘要决定磁盘文件名，用户文件名仅作下载元数据。
  相同内容共用存储；文件以原子重命名写入本地 `data/console-assets`。
  PostgreSQL 只保存管理记录，备份必须同时包含资源目录。取消表单或归档记录不删除文件；
  当前没有自动垃圾回收、总存储配额、数字签名或客户端自动更新。
- `GET /api/v1/sharing/devices/:id/details` 返回设备详情、注册状态和最近保留事件；
  `GET /api/v1/sharing/history?deviceId=...` 返回可选设备范围的事件。
  注册、审批、拒绝、停用与发布撤销事件随修改原子保存，合计保留最近 1000 条。
  不补造历史数据，也不把注册请求当作持续在线／心跳证据。

## 交互规则

各管理模块沿用列表、草稿弹窗和详情侧栏。列表搜索包含业务字段。
资源编辑器上传成功后回填下载地址与摘要；下载需要管理会话。
任务列表将审核状态与任务进度同时显示，完成／取消弹窗收集结果。
策略页面提供独立模拟表单，修改输入即清除旧结果。
设备详情从列表打开，历史页签展示真实事件；共享中心页签限定对应目录类型。
未关联的设备单独显示，缺失的关联设备明确提示。
