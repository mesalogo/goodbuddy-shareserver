# ShareServer 产品功能列表

## 文档用途

本文用于确定 ShareServer 的产品信息架构、页面范围和功能状态。功能按“模块、页面、Tab、功能”组织，页面结构先于功能细节确定。

状态含义如下：

| 状态 | 含义 |
| --- | --- |
| 已实现 | 代码和自动化验证已覆盖，范围以实施进度中的证据为准 |
| 部分实现 | 已有可运行功能，但生产验收或关键依赖尚未完成 |
| 设计中 | 已形成产品和技术设计，尚未作为生产功能交付 |
| 待规划 | 已进入产品方向，页面和接口仍需进一步确定 |

ShareServer 是 GoodBuddy 的独立组织后台。成员的日常操作主要在 GoodBuddy 中完成，ShareServer 负责设备目录、能力发布、授权、任务、模型网关、文档和审计等组织能力。当前仓库已经包含本地共享目录和真实转发的本地模型网关，生产身份、组织隔离、设备控制连接和工具执行尚未完成。

## 页面组织规则

- 一级导航按业务对象分组，页面只负责一个相对完整的管理对象。
- 页面内 Tab 按查看范围或操作阶段划分，不能把配置、运行记录和统计混在同一个 Tab。
- 列表、详情和创建表单属于同一 Tab 的交互，不单独扩成一级导航。
- Tab 名称使用产品对象或用户任务命名，避免使用“其他”“更多功能”等收纳式名称。
- 当前未接入的 Tab 可以进入，但必须显示待接入边界，不生成示例数据，也不提供不会生效的操作。

## 2. GoodBuddy 服务

### 2.1 模型网关

模型网关为 GoodBuddy 和兼容客户端提供统一的模型请求入口。网关保存上游配置和模型映射，转发请求并记录有界调用元数据，不托管模型，也不在网关执行模型返回的工具调用。

| Tab | 主要功能 | 当前状态 |
| --- | --- | --- |
| 概览 | 网关地址、启用上游数、启用模型数、访问密钥数、最近调用状态和管理边界 | 部分实现 |
| 上游服务 | 添加、编辑、启停上游；保存 Base URL、协议和认证方式；凭据留空则保留，填写则覆盖；发现远端模型 | 部分实现 |
| 模型目录 | 查看模型别名、远端模型名、所属上游和启用状态；手工添加或编辑映射；启停映射 | 部分实现 |
| 访问密钥 | 创建客户端 Bearer Key；按模型绑定授权范围；查看名称和状态；撤销密钥 | 部分实现 |
| 请求测试 | 选择可用模型发送真实非流式请求；显示结果；取消请求；提示数据去向和费用风险 | 部分实现 |
| 调用审计 | 查看时间、请求编号、模型、上游、访问密钥、流式方式、结果、HTTP 状态、耗时、Token 用量和错误码 | 部分实现 |
| 客户端接入 | 查看客户端 Base URL、协议、模型 ID 和配置步骤；说明客户端只使用网关访问 Key | 部分实现 |

模型网关的页面关系如下：

```text
概览
  ├─ 上游服务       管理外部模型服务连接
  ├─ 模型目录       管理客户端可见的模型映射
  ├─ 访问密钥       管理客户端调用凭据和模型授权
  ├─ 请求测试       验证模型请求转发
  ├─ 调用审计       查看调用结果和运行元数据
  └─ 客户端接入     将已配置模型交给 GoodBuddy 或兼容客户端使用
```

网关后续扩展仍放在对应 Tab：

- 上游服务增加健康状态、延迟和错误率。
- 模型目录增加能力标签、路由规则和备用上游。
- 访问密钥增加主体、组织、有效期、配额和撤销原因。
- 请求测试增加工具调用和流式场景的受控验证。
- 调用审计增加 `traceId`、父子请求、决策、失败阶段和链路详情。
- 客户端接入增加按组织或用户组分发配置的能力。

组织身份、工具级权限、三态策略、供应商切换、配额、成本统计和工具执行属于后续网关能力，不能写成当前 Tab 已提供的操作。

## 当前交付边界

当前仓库可以运行的功能集中在两个页面域：

1. GoodBuddy 接入和共享中心：保存并读取本地设备登记、能力发布和知识发布元数据。
2. 模型网关：保存上游、加密凭据、模型映射和访问 Key，支持真实模型发现、请求转发、请求测试和有界调用审计。

组织认证、组织隔离、生产设备认证、设备控制连接、工具执行、任务路由、完整 Desktop Office 编辑与源文件回写、实时协作、成本控制和联邦仍属于设计或后续实现范围；私网 Web 的 DOCX 保存链路已实现。接口、状态规则和验证证据分别由 [PRD](./prd.md)、[功能逻辑](./logic-design.md)、[技术设计](./technical-design.md) 和 [实施进度](./progress.md) 维护。
